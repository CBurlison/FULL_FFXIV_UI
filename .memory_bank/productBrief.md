# Product Brief: FFXIV UI

## Overview
FFXIV UI is a comprehensive interface add-on for World of Warcraft, designed and optimized for **both WoW Retail (Patch 12.0.0+) and WoW Forever (Build 16001)**. It brings the aesthetic, layout philosophy, and design language of Final Fantasy XIV to World of Warcraft across both platforms.

## Core Goals
1. **Themed Aesthetics:** Recreate the distinctive FFXIV visual language—rounded dark/light panels, gold accents, Axis fonts, clean window chrome, and custom micro-menu artwork.
2. **Controller & Modern Ergonomics:** Support controller cross hotbars, device-aware button glyphs, streamlined action bars, and accessible navigation.
3. **Immersive Unit & Group Frames:** Compact player, target, focus, party, raid, and pet resource bars with class icons and clear status displays.
4. **Enhanced Utility:** Custom searchable spellbook, rounded crafting logs, unified inventory bag grids, item/spell tooltip revamps, and an informational non-clickable enemy list.
5. **Spec-Driven Quality:** Maintain rigid architectural standards and component specifications through a centralized Memory Bank.
