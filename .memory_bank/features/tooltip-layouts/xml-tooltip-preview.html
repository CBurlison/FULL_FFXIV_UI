1. Shared template anatomy

One virtual template, FFXIV_TooltipTemplate, holds the surfaces below. Every section is created hidden. Lua shows the sections a tooltip uses, fills them, and reuses a fixed pool of trait cells, stat pairs and text rows. No row frames are created at runtime.

XML round-frame slices, header icon, name FontString (wrapping), type FontString under the icon, the owned/max count and housing indicator on the type row, the trait cell pool (value FontString plus bar), the band, the stat pair pool, divider, comparison heading, effect and flavor text FontStrings, the money line.
Lua the shine gradient (kept in code, per your decision), data, values and colours, which sections show, native line capture and restore, measured reflow, caching.
hidden every section starts hidden. Lua shows only what the tooltip uses.

8. Layout rules derived from the references

Binding line is centred at the top; the body is left-aligned from one shared inset.
Icon and name share one row. The icon is 36px and the name is vertically centred beside it, left-aligned, and wraps to show the full name.
The item type sits on its own line under the icon. The owned/max count, or the housing indicator when present, sits on the same line, right-aligned.
Trait cells: label above a right-aligned value, with a thin bar under each cell. Used by spell, weapon and consumable.
The item-level band spans the full tooltip width.
Stat pairs: left and right columns; secondary stats that do not apply to the player's spec are dimmed.
Comparison lines: negatives red, positives green, with the heading in yellow.
Flavor text is measured after wrapping, so the bottom padding holds even when it is the last section.
The Sell Price row and the Durability row use the same left edge as the body text, and coin icons follow the amount.
Sections are chained with the divider. Lua does not add a gap when a section is hidden.
